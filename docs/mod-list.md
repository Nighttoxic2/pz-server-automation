## Installation

### Via Steam Workshop (Recommended)
1. Subscribe to each mod in Steam Workshop
2. Add Workshop IDs to `Zomboid/Server/sarvarpz/workshop.txt` (one per line)
3. Server auto-downloads on startup

### Manual (For non-Workshop mods)
```bash
# Place .mod files in:
/home/trilayer/Servers/SarvarPZ/Zomboid/Server/sarvarpz/mods/

# Edit mod.info for load order
```

---

## Load Order (Critical)
```
1. Core game files
2. Map mods (Bedford Falls, Raven Creek, etc.)
3. Hydrocraft (must load early)
4. Weapon packs (Brita's, etc.)
5. Vehicle mods
6. QoL mods
7. Admin tools (last)
```

| Vehicle mods | Towing | Tow hitch conflicts | Load towing last |

## Updating Mods
```bash
# 1. Update workshop.txt with new IDs
# 2. Restart server (auto-downloads)
# 3. Check logs for errors:
journalctl -u sarvarpz -f | grep -i "mod\|workshop\|error"

# 4. If conflicts, adjust load order in servertest.ini
```

## Mod Configuration
Most mods configure via:
- `Zomboid/Server/sarvarpz/mods/<ModName>/mod.ini`
- In-game admin panel (Admin Tools Plus)
- Server sandbox options (`servertest.ini`)

Document per-mod config changes in `docs/mod-config.md`.
